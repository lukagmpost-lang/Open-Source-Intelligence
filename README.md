# Open-Source-Intelligence
Google Maps, Instagram, LinkedIn and Telegram walk into a bar and get shitfaced. In the morning they wake up and turns out last night they forgot to use protection. Taken that they are all under 18 years old, they do not have money for the abortion and they decide to have the baby. They name it Osi, Open Source Intelligence.

Multi-Layer Social Graph Analysis Tool

Tool that maps social connections that maps social connections across 
multiple platforms into a weighted, multi-layer graph. The goal is to identify communities and vulnerabilities in the society.

GitHub — followers, following, mutual
- Reddit — friends, subreddit memberships, comment history
- Steam — friends list, game library
- Instagram - followers, comments, likes, reposts
- Facebook - followers, comments, likes, reposts, groups
- Telegram - gifts network, public and private channels
- Discord - servers, activity
- Spotify - playlists
